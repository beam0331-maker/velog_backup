<h3 id="1-프로세스-제어-및-스케줄링">1. 프로세스 제어 및 스케줄링</h3>
<p><strong>1.1 프로세스 제어</strong></p>
<ul>
<li><strong>개념:</strong> 현재 시스템에서 실행 중인 프로세스를 모니터링하고 포그라운드/백그라운드 상태를 제어한다.</li>
<li><strong>명령어:</strong><ul>
<li><code>ps -ef</code>: 시스템에서 실행 중인 모든 프로세스의 정보를 출력한다.</li>
<li><code>kill -9 &lt;PID&gt;</code>: 지정한 프로세스를 강제로 종료한다.</li>
<li><code>&lt;명령어&gt; &amp;</code>: 작업을 백그라운드로 실행한다.</li>
<li><code>ctrl + z|c</code> : 프로세스 중지 | 종료</li>
<li><code>jobs</code>: 백그라운드 및 일시 정지 상태인 작업들의 목록과 작업 번호를 확인한다.</li>
<li><code>fg / bg</code>: 멈춰놓은 작업이나 특정 작업을 포그라운드 또는 백그라운드로 실행한다.</li>
</ul>
</li>
</ul>
<p><strong>1.2 작업 스케줄링 (crontab)</strong></p>
<ul>
<li><p><strong>개념:</strong> 정해진 시간에 특정 작업을 반복처리하도록 지정한다.</p>
</li>
<li><p><strong>옵션:</strong></p>
<ul>
<li><code>crontab -e</code>: 예약된 작업을 작성하고 수정하는 편집기를 연다.</li>
<li><code>crontab -l</code>: 현재 예약된 작업 목록을 확인한다.</li>
<li><code>crontab -r</code>: 예약된 작업을 모두 삭제한다.</li>
</ul>
</li>
<li><p><strong>문법:</strong> <code>분 시 일 월 요일 &lt;실행명령어&gt;</code> 형식으로 스케줄을 예약한다.</p>
</li>
<li><p><strong>작업 스케줄링 bash 예시 코드:</strong></p>
<pre><code class="language-bash"># 매일 3시에 backup.sh 스크립트를 실행한다
0 3 * * * /path/to/backup.sh

# 매주 일요일 자정에 clean.sh 스크립트를 실행한다
0 0 * * 0 /path/to/clean.sh

# 평일(월~금) 9시부터 18시까지 매시간 work.sh 스크립트를 실행한다
0 9-18 * * 1-5 /path/to/work.sh</code></pre>
</li>
<li><p>** 팁:** 스케줄러 등록 시 정상 출력과 에러를 통합 기록하려면 리다이렉션을 결합한다 (<code>&amp;&gt; /var/log/backup.log</code>).</p>
</li>
</ul>
<h3 id="2-네트워크-다운로드-및-런레벨">2. 네트워크 다운로드 및 런레벨</h3>
<p><strong>2.1 네트워크 다운로드</strong></p>
<ul>
<li><strong>개념:</strong> <code>wget</code> 명령어를 통해 http에서 파일을 다운로드한다.</li>
<li><strong>문법:</strong> <code>wget [옵션] &lt;URL&gt;</code> </li>
<li><strong>옵션:</strong><ul>
<li><code>-O 파일명</code>: 다른 이름으로 저장한다.</li>
<li><code>-c</code>: 이어 받기 (continue) 기능을 수행한다.</li>
<li><code>-b</code>: 백그라운드로 다운로드한다.</li>
<li><code>-r</code>: 링크를 따라가면 재귀적으로 다운로드한다.</li>
<li><code>-P 디렉터리</code>: 특정 디렉터리에 지정하여 저장한다.</li>
<li><code>--show-progress</code>: 다운로드 진행률을 확인한다.</li>
<li><code>--limit-rate=&lt;속도&gt;</code>: 초당 다운로드 속도를 제한한다 (예: 10k).</li>
<li><code>-l 파일명</code>: 지정한 파일 안의 URL 목록을 읽어 여러 개를 다운로드한다.</li>
</ul>
</li>
</ul>
<p><strong>2.2 런레벨 (Runlevel)</strong></p>
<ul>
<li><p><strong>개념:</strong> <code>init</code> 프로세스는 시스템의 단계를 일곱 단계로 구분하고, 각 단계 따라 관련 쉘 스크립트를 실행한다.</p>
</li>
<li><p><strong>모든 런레벨 종류:</strong></p>
<ul>
<li><code>0</code>: 시스템 종료</li>
<li><code>1</code>, <code>S</code>: 단일 사용자 모드</li>
<li><code>2</code>: 다중 사용자 모드 (NFS를 지원하지 않음)</li>
<li><code>3</code>: 다중 사용자 모드 (NFS 지원)</li>
<li><code>4</code>: 사용자 정의 (거의 사용하지 않음)</li>
<li><code>5</code>: X11 상태로 부팅 (GUI 환경)</li>
<li><code>6</code>: 재시작</li>
</ul>
</li>
<li><p><strong>런레벨 변경 bash 예시 코드:</strong></p>
<pre><code class="language-bash"># 현재 런레벨 확인
systemctl get-default 

# 시스템을 종료한다 (런레벨 0)
init 0

# 텍스트 모드 다중 사용자로 전환한다 (런레벨 3)
init 3

# 그래픽 모드(GUI)로 전환한다 (런레벨 5)
init 5

# 시스템을 재부팅한다 (런레벨 6)
init 6

# 런레벨 영구변경
# GUI
systemctl set-default graphical.target
# CUl
systemctl set-default multi-user.target  
</code></pre>
</li>
</ul>
<h3 id="3-쉘-스크립트-기초-1-변수와-규칙">3. 쉘 스크립트 기초 1: 변수와 규칙</h3>
<ul>
<li><strong>쉘(Shell):</strong>  사용자의 명령을 받아서 os의 커널에 전달해서 실행하도록 하는 프로그램.</li>
<li><strong>문법:</strong> 스크립트 최상단에 <code>#!/bin/bash</code> 형태의 쉬뱅(Shebang)을 명시하여 이 파일을 bash로 실행하라는 의미를 전달한다.</li>
<li><strong>특수 파라미터 (Special Variables):</strong> 쉘이 미리 만들어 둔 특별한 변수들이다.<ul>
<li><code>$0</code>: 실행된 쉘 스크립트의 파일명</li>
<li><code>$1, $2...</code>: 스크립트 실행 시 전달받은 첫 번째, 두 번째 인자 (10부터는 중괄호 사용 <code>${10}</code>)</li>
<li><code>$#</code>: 스크립트에 전달된 인자의 개수</li>
<li><code>$@</code>: 전달된 모든 인자 전체 (개별 항목으로 유지)</li>
<li><code>$*</code>: 전달된 모든 인자 전체 (모든 인자를 하나의 문자열로 합침)</li>
<li><code>$$</code>: 현재 실행 중인 쉘 또는 스크립트의 PID</li>
<li><code>$?</code>: 바로 직전에 실행한 명령어의 결과코드 (0:성공 , 이외값:실패)</li>
<li><code>$!</code>: 가장 최근에 백그라운드로 실행한 프로세스 PID</li>
</ul>
</li>
</ul>
<p><strong>📝 Bash 스크립트 기본 구조 예시</strong></p>
<pre><code class="language-bash">  #!/bin/bash
  NAME=&quot;Linux&quot;
  echo &quot;Hello, $NAME!&quot;
  echo &quot;전달된 전체 인자: $@&quot;</code></pre>
<p><strong>🔥 Bash 쉘의 엄격한 공백(띄어쓰기) 규칙</strong></p>
<ul>
<li>변수 선언 시 <code>=</code> 기호 주변에 공백 없이 지정해야 강제할 수 있다.</li>
<li>조건문 <code>[[ ]]</code> 사용 시 안쪽 양끝과 연산자 주변에는 무조건 공백이 있어야 한다.</li>
</ul>
<h3 id="4-쉘-스크립트-기초-연산자">4. 쉘 스크립트 기초 연산자</h3>

<li><strong><code>$(( ))</code> 또는 <code>let</code>:</strong> 산술 연산을 수행할 때 사용한다. (예: <code>result=$(( a + b ))</code>, <code>let result=a+b</code>)</li>

</li>
</ul>

<h3 id="5-쉘-스크립트-기초-2-제어문-배열-함수">5. 쉘 스크립트 기초 2: 제어문, 배열, 함수</h3>
<p>쉘 스크립트는 <code>if</code>, <code>case</code>, <code>for</code> 등의 제어 구조와 변수, 함수, 배열 등의 구성요소를 포함한다.</p>
<p><strong>① <code>if</code> 조건문 (파일 유효성 검사 예시)</strong></p>
<pre><code class="language-bash">  # -f 옵션으로 특정 파일이 일반 파일로 존재하는지 검사한다
  if [[ -f &quot;/var/log/syslog&quot; ]]; then
      # 파일이 존재하면 백업 디렉터리로 복사한다
      cp /var/log/syslog /backup/
  else
      # 파일이 존재하지 않으면 에러 메시지를 출력 후 스크립트 종료
      echo &quot;파일을 찾을 수 없습니다.&quot;
      exit 1
  fi</code></pre>
<p><strong>② <code>case</code> 조건문 (서비스 제어 예시)</strong></p>
<pre><code class="language-bash">  # 입력받은 첫 번째 인자($1)의 값에 따라 분기 처리한다
  case &quot;$1&quot; in
      start) 
          # 인자가 'start'일 경우 실행
          echo &quot;서비스를 시작합니다.&quot; 
          ;;
      stop)  
          # 인자가 'stop'일 경우 실행
          echo &quot;서비스를 종료합니다.&quot; 
          ;;
      *)     
          # 그 외 모든 패턴일 경우 사용법 안내
          echo &quot;사용법: $0 {start|stop}&quot; 
          ;;
  esac</code></pre>
<p><strong>③ <code>for</code> 반복문 및 배열 (IP 리스트 순회 예시)</strong></p>
<pre><code class="language-bash">  # 배열 선언 시 쉼표가 아닌 공백으로 값들을 구분한다
  IP_LIST=(&quot;10.0.0.1&quot; &quot;10.0.0.2&quot;)

  # 배열 내 모든 요소(@)를 순회하며 ip 변수에 차례대로 할당한다
  for ip in &quot;${IP_LIST[@]}&quot;; do
      echo &quot;접속 대상 IP: $ip&quot;
  done</code></pre>

<h3 id="🔥-오늘의-회고">🔥 오늘의 회고</h3>
<blockquote>
<p><strong>배열 길이와 인덱스 원리</strong></p>
<ul>
<li>배열을 다룰 때 <code>#</code> 기호는 배열 요소의 전체 개수나 문자열의 길이를 반환한다.</li>
<li>반대로 <code>!</code> 기호는 간접 참조를 의미하여 배열의 실제 값(Value)이 아닌 인덱스 번호(Key)를 반환한다.</li>
</ul>
</blockquote>
<blockquote>
<p><strong>함수(Function)의 리턴 한계 극복</strong></p>
<ul>
<li>쉘 스크립트 함수 내에서 <code>return</code>은 오직 숫자값만 반환할 수 있다.</li>
<li>문자열을 반환(리턴)하려면 함수 내부에서 <code>echo</code>를 이용하여 출력해야 한다.</li>
</ul>
</blockquote>
