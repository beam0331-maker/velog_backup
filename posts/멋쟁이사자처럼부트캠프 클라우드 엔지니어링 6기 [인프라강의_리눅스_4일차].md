<h3 id="1-입출력-방향-제어-리다이렉션-redirection">1. 입출력 방향 제어: 리다이렉션 (Redirection)</h3>
<hr />
<ul>
<li><strong>개념 :</strong> 명령어의 표준 입출력 방향을 모니터나 키보드가 아닌 특정 파일로 변경하는 기술이다.</li>
</ul>
<table>
<thead>
<tr>
<th align="left">통로 / 기호</th>
<th align="left">실무 활용 상세 설명</th>
</tr>
</thead>
<tbody><tr>
<td align="left"><strong><code>0</code> (<code>&lt;</code>)</strong></td>
<td align="left">표준 입력. 파일의 내용을 명령어의 입력으로 전달한다.</td>
</tr>

<td align="left">표준 출력(정상). <code>&gt;</code>는 파일 덮어쓰기, <code>&gt;&gt;</code>는 기존 내용 하단에 이어 붙이기(Append)를 수행한다.</td>
</tr>
<tr>
<td align="left"><strong><code>2</code> (<code>2&gt;</code>)</strong></td>
<td align="left">표준 에러(비정상). 실행 중 발생한 오류나 비정상적인 메시지만 파일로 분리하여 저장한다.</td>

</tr>
</tbody></table>

<ul>
<li><strong>정상 출력만 저장:</strong> <code>ls file.txt &gt; success.txt</code> (에러가 발생하면 화면에 출력됨)</li>
<li><strong>에러 출력만 저장:</strong> <code>ls wrong.txt 2&gt; error.txt</code> (정상 결과는 화면에 출력됨)</li>
<li><strong>완벽 분리 저장:</strong> <code>ls file.txt wrong.txt &gt; success.txt 2&gt; error.txt</code></li>
</ul>

<h3 id="3-사용자-및-그룹-관리">3. 사용자 및 그룹 관리</h3>
<hr />
<ul>
<li><strong>문법 :</strong> <code>useradd [옵션]... &lt;사용자명&gt;</code> / <code>passwd &lt;사용자명&gt;</code></li>
<li><strong>개념 :</strong> 시스템 접근을 통제하기 위해 사용자를 생성하고, 텍스트 파일(<code>/etc/passwd</code> 등)을 통해 권한 구조를 관리한다.</li>
</ul>
<table>
<thead>
<tr>
<th align="left">옵션 및 설정</th>
<th align="left">실무 활용 상세 설명</th>
</tr>
</thead>
<tbody><tr>
<td align="left"><strong><code>-m</code></strong></td>
<td align="left"><code>/home/계정명</code> 경로에 사용자의 홈 디렉터리를 자동으로 생성한다.</td>
</tr>
<tr>
<td align="left"><strong><code>-s</code></strong></td>
<td align="left">사용자가 접속했을 때 사용할 기본 쉘(예: <code>/bin/bash</code>)을 지정한다.</td>
</tr>
<tr>
<td align="left"><strong><code>-G</code></strong></td>
<td align="left">계정을 생성함과 동시에 특정 '추가 그룹(Secondary Group)'에 편입시킨다.</td>
</tr>
</tbody></table>
<p><strong>📝 <code>/etc/passwd</code> 파일 구성요소</strong>
이 파일은 콜론(<code>:</code>)을 기준으로 총 7개의 필드로 나뉘어 사용자의 핵심 정보를 담고 있다.</p>
<blockquote>
<p><strong>예시:</strong> <code>user1 : x : 1000 : 1000 : 테스트계정 : /home/user1 : /bin/bash</code></p>
</blockquote>
<ol>
<li><strong><code>user1</code></strong> : 로그인할 때 사용하는 계정명 (ID)</li>
<li><strong><code>x</code></strong> : 비밀번호가 암호화되어 <code>/etc/shadow</code> 파일에 별도로 보관되어 있음을 의미</li>
<li><strong><code>1000</code> (UID)</strong> : 시스템이 사용자를 식별하는 고유 식별 번호 (User ID)</li>
<li><strong><code>1000</code> (GID)</strong> : 사용자가 소속된 기본 그룹의 고유 번호 (Group ID)</li>
<li><strong><code>테스트계정</code></strong> : 해당 계정에 대한 설명이나 코멘트</li>
<li><strong><code>/home/user1</code></strong> : 사용자가 로그인했을 때 할당받는 홈 디렉터리 경로</li>
<li><strong><code>/bin/bash</code></strong> : 로그인 시 기본으로 실행될 쉘(Shell) 프로그램</li>
</ol>
<h3 id="4-파일-접근-권한-관리-chmod">4. 파일 접근 권한 관리 (chmod)</h3>
<hr />
<ul>
<li><strong>문법 :</strong> <code>chmod [옵션]... &lt;8진수 권한 또는 기호&gt; &lt;파일명&gt;...</code></li>
<li><strong>개념 :</strong> 파일 및 디렉터리에 대해 소유자(u), 그룹(g), 기타 사용자(o)가 읽기(r), 쓰기(w), 실행(x)을 할 수 있는지 통제한다.</li>
</ul>
<table>
<thead>
<tr>
<th align="left">권한 / 방식</th>
<th align="left">실무 활용 상세 설명</th>
</tr>
</thead>
<tbody><tr>
<td align="left"><strong><code>r</code> (4) / <code>w</code> (2)</strong></td>
<td align="left"><code>r</code>은 파일 내용이나 폴더 목록을 읽는 권한, <code>w</code>는 내용 수정 및 폴더 내 파일 생성/삭제 권한이다.</td>
</tr>
<tr>
<td align="left"><strong><code>x</code> (1)</strong></td>
<td align="left">파일은 스크립트 등을 실행하는 권한이며, <strong>디렉터리(폴더)는 그 안으로 진입(<code>cd</code>)할 수 있는 권한</strong>이다.</td>
</tr>
<tr>
<td align="left"><strong>숫자 모드</strong></td>
<td align="left"><code>chmod 755 file.txt</code>처럼 권한의 합을 8진수로 표기하는 방식으로, 실무에서 가장 보편적으로 사용된다.</td>
</tr>
</tbody></table>
<h3 id="🔥-오늘의-딥다이브-회고">🔥 오늘의 딥다이브 (회고)</h3>
<hr />
<h4 id="1-devnull을-활용한-에러-처리와-스트림-통합">1. <code>/dev/null</code>을 활용한 에러 처리와 스트림 통합 <code>&amp;&gt;</code></h4>
<ul>
<li>시스템 전체 경로 등을 검색할 때 권한 부족으로 인한 에러 메시지가 화면을 가득 채우는 경우가 있다. 이때 명령어 끝에 <code>2&gt; /dev/null</code>을 명시하면, 불필요한 에러 출력은 버리고 정상적인 검색 결과만 화면에서 확인할 수 있다.</li>
<li>크론(Cron)과 같은 스케줄러를 통해 스크립트를 자동 실행할 때, <code>&amp;&gt;</code> (또는 <code>2&gt;&amp;1</code>)를 사용하면 정상 출력과 에러 메시지를 하나의 로그 파일로 통합할 수 있어 문제 발생 시 원인 파악이 용이하다.</li>
</ul>
<h4 id="2-웹-서버-및-시스템-기본-권한-세팅-755--644">2. 웹 서버 및 시스템 기본 권한 세팅 (755 / 644)</h4>
<p>시스템 보안과 안정적인 서비스 운영을 위해 다음 두 가지 권한 세팅을 기본 원칙으로 삼는다.</p>
<ul>
<li><strong>디렉터리 <code>755</code>:</strong> 소유자에게만 쓰기(2) 권한을 부여하고, 외부 사용자는 디렉터리 내부 진입(<code>x</code>)과 목록 확인(<code>r</code>)만 가능하도록 제한한다.</li>
<li><strong>일반 파일 <code>644</code>:</strong> 텍스트 문서나 로그 파일은 실행될 필요가 없으므로 외부 사용자의 실행(<code>x</code>) 권한을 제거하여 보안 위험을 방지한다.</li>
</ul>
